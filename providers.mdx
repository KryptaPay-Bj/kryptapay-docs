# Supported Payment Providers

KryptaPay provides a unified API for processing payments and payouts across multiple payment providers. Instead of integrating with each provider individually, you integrate once with KryptaPay and gain access to a growing network of payment methods.

## Unified API

Regardless of the payment provider, all KryptaPay integrations use the same API conventions:

- Consistent authentication
- Standardized request and response formats
- Unified error codes
- Common transaction lifecycle
- Idempotent write operations
- Webhook notifications for asynchronous events

This allows you to add new payment providers with minimal or no code changes.
